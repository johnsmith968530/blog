## Overview
The paper introduces a fine-tuning framework that addresses the problem of **Slack Drift**—the degradation of source task knowledge during the adaptation to a new target task. The method achieves this by partitioning the neural network into two distinct functional components: a **Universal Core** (frozen/protected) and a **Plastic Slack** (flexible/learning).

## Key Methodology

### 1. Structural Partitioning (The Core-Slack Split)
The algorithm identifies neurons to be part of the "Core" based on their functional capacity ($\|f_i\|_H$).
*   **Universal Core:** High-capacity neurons are identified via a global threshold ($\tau$) and frozen ($F_i = 0$) to protect existing source knowledge.
*   **Plastic Slack:** Lower-capacity or inactive neurons are designated as "Slack" ($F_i = 1$), allowing them to learn the new target task.
*   **Connection Masking:** To prevent "Slack drift" from leaking into the "Core," the method severs specific cross-connections where a plastic neuron feeds into a frozen core neuron.

### 2. Elastic Target Fine-Tuning
The fine-tuning process uses a modified gradient descent approach:
*   **Gradient Nullification:** During backpropagation, gradients are masked using a mask $\Phi$. This ensures that only the weights in the "Plastic Slack" are updated, while the "Core" remains pristine.
*   **Dynamic Decoupling:** By nullifying gradients for the frozen core ($\Phi \odot \nabla_{\theta} L_{target}$), the model prevents the target task's gradients from corrupting the source task's weights.

### 3. Optimization via Harmonic Score (H-Score)
To balance the trade-off between target task accuracy and source task preservation, the method employs a **Dual-Domain Evaluation** strategy:
*   **H-Score:** A harmonic mean is calculated between the target accuracy ($Acc_{tgt}$) and the source accuracy ($Acc_{src}$) after masking out the slack drift.
*   **Optimization Goal:** The fine-tuning process seeks to maximize this `H-Score` to ensure the model performs well on the new task without losing its original capabilities.
